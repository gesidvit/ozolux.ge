# OZOLUX — лендинг профессионального озонирования (Батуми · Кобулети)

Статический одностраничный сайт. Без сборки и бэкенда — открывается в любом браузере
и размещается на любом хостинге (GitHub Pages, Netlify, Vercel, обычный хостинг).

## Структура
```
Озонирование/
├── index.html        # вся страница
├── styles.css        # оформление (палитра «морская лазурь» в :root)
├── script.js         # меню, калькулятор, переключение языков, отправка заявки
├── i18n.js           # переводы RU / KA / EN
├── README.md         # этот файл
└── assets/
    ├── logo.svg          # логотип OZOLUX
    ├── favicon.svg       # иконка вкладки
    └── mascot-hero.svg   # маскот — супергерой свежего воздуха
```

## ⚙️ Как подставить свои контакты (самое важное)
Откройте **`script.js`** — в самом верху блок `CONFIG`. Поменяйте 5 значений:

```js
const CONFIG = {
  PHONE_DISPLAY: "+995 5XX XXX XXX",   // как телефон показан на сайте
  PHONE_TEL:     "+9955XXXXXXXX",      // для кнопки «позвонить» (без пробелов)
  WHATSAPP:      "9955XXXXXXXX",       // номер WhatsApp, формат БЕЗ "+", пробелов и скобок
  TELEGRAM:      "ozolux",             // ваш Telegram-username без "@"
  EMAIL:         "info@ozolux.ge"      // почта
};
```

Пример: если ваш номер **+995 555 12 34 56**, то:
- `PHONE_DISPLAY: "+995 555 12 34 56"`
- `PHONE_TEL: "+995555123456"`
- `WHATSAPP: "995555123456"`

Телефон, email, кнопки WhatsApp/Telegram (в шапке, форме, футере и плавающая кнопка)
подставятся автоматически из этого блока.

> Telegram: если у вас нет username, можно указать номер телефона — ссылка `t.me/<номер>`
> тоже работает. Но username (`@ozolux`) надёжнее.

## Как работает форма заявки
Пользователь заполняет форму и нажимает **«Написать в WhatsApp»** или **«Написать в Telegram»**.
Заявка открывается в соответствующем мессенджере с уже готовым текстом (имя, телефон, тип объекта,
площадь, город, комментарий). Бэкенд не нужен.

## Языки (RU / KA / EN)
Сайт многоязычный: переключатель 🌐 в шапке (Русский / ქართული / English).
Выбор запоминается в браузере, заявка в WhatsApp/Telegram уходит на выбранном языке.
- Все переводы — в файле **`i18n.js`**: объект `I18N` с тремя блоками `ru`, `ka`, `en`.
  Чтобы поправить текст — найдите нужный ключ и измените значение в соответствующем языке
  (ключи одинаковы во всех языках). Например `"hero.h1"`.
- Язык по умолчанию для новых посетителей — русский. Изменить: переменная `currentLang`
  в `script.js` (fallback `"ru"`).
- Элементы на странице связаны с переводами через атрибут `data-i18n="ключ"` в `index.html`.

## Как изменить тексты и цены
- Тексты — в `i18n.js` (см. раздел «Языки» выше). Разметка — в `index.html`.
- Ставка калькулятора (5–6 ₾/м², минимум 200 ₾) — в `script.js`, переменные `RATE_MIN`, `RATE_MAX`, `MIN_ORDER`.
- Цвета — в `styles.css`, блок `:root` (переменные `--azure-600`, `--aqua-400` и т.д.).

## Блок «До и после» (примеры работ)
Интерактивный компаратор: посетитель тянет ползунок и сравнивает «до/после».
- Изображения лежат в **`assets/cases/`**: пары `caseN-before.*` и `caseN-after.*` (сейчас 4 пары).
- **Сейчас это оригинальные иллюстрации (SVG)** — не фотографии. Чтобы показать реальные работы,
  замените файлы на свои **фото** (например `case1-before.jpg` / `case1-after.jpg`) и обновите пути
  в `index.html` (секция `BEFORE / AFTER`). Важно: фото «до» и «после» должны быть сняты **с одной точки**
  и одного размера (соотношение сторон 4:3), иначе ползунок будет «прыгать».
- Подписи под примерами и слова «До»/«После» — в `i18n.js` (ключи `ba.cap1…ba.cap4`, `ba.before`, `ba.after`).
- Добавить/убрать пример — скопируйте/удалите блок `<figure class="ba-item">…</figure>` в `index.html`.

## Как опубликовать
1. **Проверить локально:** откройте `index.html` двойным кликом (или запустите локальный сервер
   `python3 -m http.server` в этой папке и откройте `http://localhost:8000`).
2. **Выложить:** загрузите все файлы (включая папку `assets/`) на хостинг.
   Для GitHub Pages / Netlify достаточно залить содержимое этой папки.
